# Multilingual i18n Foundation

Current production language:
- English

Prepared future languages:
- Spanish / es
- Ukrainian / uk, UI label ua
- Russian / ru

Rules:
- EN remains default and current canonical version.
- ES/UK/RU are disabled until translated.
- Legacy localStorage-based locale switching has been removed from the active app path.
- No hreflang until a real translated locale is launched.
- No localized sitemap URLs until locale is public.
- No browser-language redirects.
- No query-param language switching.
- Disabled language labels must not link to untranslated pages.
