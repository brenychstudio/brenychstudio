# Spanish Localization Glossary

## 1. Localization Principle

Spanish should read as premium Spain-facing localization, not as a literal translation from English.

The tone should be clear, restrained, professional and editorial. It should keep the Brenych Studio positioning around interface systems, premium front-end work, product presentation, immersive web and case-backed proof.

Do not make the site sound like a generic web design agency.

## 2. Tone Rules

- Use European / Spain-friendly Spanish.
- Keep "premium" where it sounds natural.
- Keep "landing page" where it is more natural than "página de aterrizaje".
- Avoid over-explaining.
- Avoid cheap agency language.
- Avoid exaggerated marketing language.
- Avoid literal translations that sound heavy or artificial.
- Keep sentences slightly shorter than English when possible.
- Preserve the studio's calm, precise, editorial tone.
- Prefer concrete product, interface and proof language over broad marketing claims.
- Use neutral professional address. Avoid casual second-person overuse.

## 4. Terms To Avoid

Avoid:

- diseño web moderno
- página web bonita
- soluciones digitales increíbles
- experiencia única e impresionante
- páginas de aterrizaje, unless context requires formal literal wording
- desarrollo web barato
- agencia de diseño web genérica
- marketing digital integral
- todo en uno

These phrases make the site sound like a generic Spanish agency website. Brenych Studio should remain positioned around authored interface systems, premium front-end execution, product clarity, immersive proof and restrained commercial direction.

## 8. SEO Wording Rules

- Spanish SEO should be specific, calm and proof-led.
- Avoid keyword stuffing such as repeated "diseño web Barcelona", "agencia web premium" or "landing pages profesionales".
- Use "Brenych Studio" in titles when the page is brand-led or where brand trust helps.
- Mention Barcelona only where truthful and strategically relevant: studio context, Barcelona-specific cases, Spain-facing commercial positioning.
- Do not invent local claims such as "la mejor agencia de Barcelona".
- Service SEO should connect the service type with proof: landing pages premium, sistemas web interactivos, demos de producto, interfaces inmersivas.
- Case SEO should keep the case name, system type and proof result clear.
- Spanish titles can be slightly longer than English if needed, but should remain readable and editorial.

## 9. Notes For Spain / Barcelona Audience

- Use European Spanish vocabulary and rhythm.
- "Sitio web" is preferred for a complete digital property; "página" is acceptable for individual pages.
- "Landing page" is natural in commercial Spanish and should remain in most UI/service contexts.
- "Asesoría inmobiliaria" is better than generic "inmobiliaria" for Barcelona Private Advisory.
- "Consulta privada" fits the premium intake model better than "contacto" or "formulario".
- Keep English product names and internal feature names when they behave as branded product terms.
- Avoid sounding like a local agency directory listing. The Spanish version should feel like a precise localization of an authored studio, not a separate mass-market offer.
