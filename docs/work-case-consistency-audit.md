# Work case consistency audit

## Reference case
Barcelona Private Advisory

Reference standard for this audit:
- current hero rhythm
- current media section behavior
- current closing proof / production facts pairing
- current bottom navigation balance
- current motion restraint

## Shared polish candidates for 14B
- Strengthen the thin-case fallback in the closing zone. `whisper`, `gallery`, and `musician` all fall back to a lighter editorial narrative than the Barcelona reference because `CasePage` has strong structure but not enough proof density when `problem / approach / clarity / motion / build / links` are missing.
- Tune edge-state bottom navigation behavior. First and last cases still resolve to asymmetrical endings more often than the middle cases, even though the card/button surfaces are now closer.
- Align motion-proof caption rhythm with the newer desktop/mobile caption system. `CaseMotionProof` still uses a slightly older caption density than the rest of the page system.
- Define a minimum case payload contract in content. Not a redesign: just a shared checklist so every shipped work case has enough proof copy to support hero, closing proof, and production facts at the same premium level.

## Per-case priority for 14B
- `whisper`: first archive case, so its lighter summary/proof payload lowers the perceived standard too early.
- `musician`: strongest gap between promised cinematic direction and current proof density.
